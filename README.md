# الموقع الرسمي الجديد لعلامة ومصنع جواهر الريم | Jawahir Alreem

موقع تعريفي ومتجر استعراض عصري وفاخر ومتعدد الصفحات (Multi-Page Architecture) لعلامة **جواهر الريم للصناعة | Jawahir Alreem**، تم بناؤه وتطويره بأحدث معايير الويب العالمية:
- **React 18** مع **Vite 6** لأقصى درجات السرعة والأداء.
- **Tailwind CSS v3** مع لوحة ألوان وهوية بصرية فخمة ومخصصة.
- **React Router v7** لنظام توجيه سلس وانتقال بين الصفحات المستقلة بدون إعادة تحميل.
- **Framer Motion** لتأثيرات حركية فاخرة وانتقالات ناعمة (Micro-interactions & Smooth Transitions).
- **Lucide Icons** لأيقونات عصرية وخفيفة.

---

## 🌟 أبرز التحسينات والتطويرات المنجزة

### 1. إعادة تصميم الموقع بالكامل بشكل عصري وفاخر (Modern & Luxury UI/UX)
- اعتماد لوحة ألوان دافئة وفاخرة مستوحاة من مستحضرات التجميل والعناية بالبشرة (`#451f08`, `#e7b397`, `#f9eee8`, `#c99856`).
- بطاقات زجاجية عصرية (Glassmorphism) مع حدود متوهجة وظلال ناعمة (Soft & Elevated Shadows).
- تأثيرات لمعان ذهبي (Shimmer Shine) على الأزرار والشارات لجذب الانتباه.
- دعم كامل ومثالي للكتابة والقراءة من اليمين إلى اليسار (RTL) مع خط `Alexandria` العربي الفاخر.

### 2. فصل الصفحات وجعلها صفحات مستقلة بالكامل (Multi-Page Architecture)
بدلاً من جمع كل شيء في صفحة واحدة بروابط هاش (`#`)، تم بناء صفحات مستقلة مخصصة لكل قسم:
1. **الرئيسية (`/`)**: واجهة استقبال مبهرة، بانر ترحيبي، نبذة عن المصنع، استعراض أبرز المنتجات، آراء العميلات، الأسئلة الشائعة، ودعوة للعمل.
2. **عن جواهر الريم (`/about`)**: قصة التأسيس العريقة منذ 1999م في المدينة المنورة، الخط الزمني التفاعلي لمسيرة ربع قرن، القيم المؤسسية الأربعة، واعتمادات الجودة وهيئة الغذاء والدواء SFDA.
3. **المنتجات (`/products`)**: كتالوج متكامل مع ميزة البحث الفوري، فلترة حسب التصنيف، ترتيب حسب الأسعار أو التقييم، وبطاقات تفاعلية مع **مودال المعاينة السريعة (Product Quick View)** مع إمكانية الطلب المباشر عبر الواتساب برسالة مخصصة.
4. **التصنيفات (`/categories`)**: استعراض مفصل لكل تصنيف (باقات التوفير، روز كير، حلاوة إزالة الشعر الطبيعية) ومميزاته ومكوناته.
5. **لماذا نحن؟ (`/why-us`)**: جدول مقارنة تفاعلي وبصري (جواهر الريم مقابل المنتجات التجارية)، شرح أسرار المكونات الطبيعية الثلاثة، وشهادات العميلات وشراكات التوزيع.
6. **تواصل معنا (`/contact`)**: صفحة اتصال مستقلة متطورة مع نموذج استفسار تفاعلي، كروت اتصال مباشر، خريطة موقع المصنع في المدينة المنورة، وساعات العمل، والأسئلة الشائعة.
7. **صفحة 404 مخصصة (`*`)**: صفحة خطأ أنيقة توجه الزائر للصفحة الرئيسية وتصفح المنتجات.

### 4. دعم كامل للغتين (Arabic & English Bilingual Support)
- تبديل فوري وسلس بين اللغتين العربية والإنجليزية بضغطة زر دون الحاجة لإعادة تحميل الصفحة.
- محاذاة اتجاهية حقيقية وصارمة: اليمين لليسار (`dir="rtl"`) للغة العربية، واليسار لليمين (`dir="ltr"`) للغة الإنجليزية مع ضبط جميع العناصر والأيقونات اتجاهياً.
- نظام خطوط مزدوج فاخر: خط `Alexandria` للغة العربية وخط `Plus Jakarta Sans` للغة الإنجليزية.
- قواميس ترجمة متكاملة تشمل كافة النصوص، المنتجات، التواريخ، والرسائل.

### 5. تطبيق المعايير الهندسية والدولية الصارمة (UI/UX Standards)
- **المسافات الفاصلة ومساحات التنفس (White Space)**: اعتماد نظام شبكي مدروس يمنع أي تكدس رأسي للنصوص (`leading-[1.45]` للعناوين الكبيرة، و`leading-loose` للفقرات).
- **التسلسل البصري للخطوط (Visual Hierarchy)**: استخدام `font-bold` للعناوين والأرقام فقط، و`font-normal` لكافة الفقرات والشروحات لتوفير أقصى درجات الراحة البصرية.
- **إمكانية الوصول (WCAG 2.2 AA/AAA)**: تباين لوني مدروس للنصوص والأزرار يتجاوز معايير التباين القياسية.
- **مناطق اللمس (Touch Targets)**: جميع الأزرار والعناصر التفاعلية بحجم لا يقل عن 48×48px لسهولة التفاعل عبر الجوال.
- **واجهة متجاوبة بالكامل (Fully Responsive)**: شريط إعلانات علوي متكيف وأزرار هيدر مرنة تضمن عدم انقطاع أو تداخل أي نص عبر كافة الشاشات من 320px وحتى الشاشات الكبيرة.

## 💻 طريقة التشغيل والتطوير

### 1. تشغيل خادم التطوير المحلي
```bash
npm run dev
```

### 2. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```

### 3. معاينة ملفات الإنتاج الجاهزة
```bash
npm run preview
```
